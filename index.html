Sección 1 · Contexto del Problema
¿Cuál es el problema?
Un data center con 3 servidores debe atender 120 tareas/s al menor costo posible.

La situación

Una empresa tiene 3 servidores con diferente eficiencia. Cada segundo llegan 120 tareas de los usuarios.

El objetivo

Decidir cuántas tareas asignar a cada servidor para que el costo total sea mínimo y toda la demanda quede cubierta.

Sección 2 · Formulación Matemática
Función Objetivo y Restricción
Minimizar el costo total garantizando que toda la demanda sea atendida.
Función objetivo — Minimizar
min f(x₁, x₂, x₃) = 2x₁² + 3x₂² + x₃²
Restricción de igualdad
g(x₁, x₂, x₃) = x₁ + x₂ + x₃ − 120 = 0

Tipo de problema

Función objetivo cuadrática + restricción lineal de igualdad → escenario ideal para Multiplicadores de Lagrange.

🎙 Diego Aguilar
Sección 3 · Método de Lagrange
Fundamento del Método
En el punto óptimo, los gradientes de f y g son paralelos.
Condición necesaria de optimalidad
∇f = λ · ∇g
Función Lagrangiana ℒ
ℒ(x₁,x₂,x₃,λ) = 2x₁² + 3x₂² + x₃² − λ(x₁+x₂+x₃−120)

¿Qué es λ (lambda)?

Escalar que mide cuánto cambia el valor óptimo cuando la restricción cambia en una unidad. Tiene interpretación económica directa.

🎙 Diego Aguilar
Sección 3 · Método de Lagrange
Sistema de Ecuaciones — Derivadas Parciales
∂ℒ/∂x₁ = 0
4x₁ − λ = 0 → x₁ = λ/4
∂ℒ/∂x₂ = 0
6x₂ − λ = 0 → x₂ = λ/6
∂ℒ/∂x₃ = 0
2x₃ − λ = 0 → x₃ = λ/2
∂ℒ/∂λ = 0 — Recupera la restricción
x₁ + x₂ + x₃ = 120
🎙 Diego Aguilar
Sección 3 · Método de Lagrange
Resolución — Encontrar el valor de λ
Sustitución en la restricción
λ/4 + λ/6 + λ/2 = 120
MCM = 12
3λ/12 + 2λ/12 + 6λ/12 = 120 → 11λ/12 = 120
λ = 1440/11 ≈ 130.91
🎙 Diego Aguilar
Sección 3 · Método de Lagrange
Valores Óptimos de Asignación
Servidor S₁
x₁* = λ/4 = 360/11 ≈ 32.73 tareas/s
Servidor S₂
x₂* = λ/6 = 240/11 ≈ 21.82 tareas/s
Servidor S₃
x₃* = λ/2 = 720/11 ≈ 65.45 tareas/s
Verificación ✓
360/11 + 240/11 + 720/11 = 1320/11 = 120 ✓
